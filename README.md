# Firefly 智能座舱竞品调研简报

面向 Firefly 智能座舱团队的自动化竞品调研简报工具，用于定期采集、整理和发布车企、手机与可穿戴生态中的软件功能更新，为座舱产品规划、功能机会识别和竞品动态复盘提供持续输入。

## 最新一期

- [FYDC 调研报告 2026-09-21](./fydc-research-2026-09-21.html)

## 项目用途

- 定期汇总竞品 OTA、发布会、产品官网、公开报道等渠道中的软件功能变化。
- 将分散信息沉淀为可阅读、可追溯、可持续更新的简报页面。
- 帮助 Firefly 智能座舱团队快速识别功能趋势、体验亮点、产品空白和后续调研议题。
- 支持以周报/阶段报告形式对外展示自动化竞品研究能力。

## 技术路径

本项目的推荐技术路线采用 LangGraph 架构，将竞品调研流程拆分为可编排、可观测、可人工复核的多个节点：

1. 数据采集节点
   - 定期从公开网页、媒体报道、品牌公告、应用商店更新记录等来源采集信息。
   - 保留原始链接、发布时间、品牌、产品线和内容片段，确保简报结论可回溯。

2. 信息清洗节点
   - 对重复内容、营销噪声和低相关信息进行过滤。
   - 统一品牌、车型、设备、功能类别、发布日期等字段。

3. 功能分类节点
   - 按智能座舱关注维度进行自动归类，例如导航、语音交互、AI 助手、娱乐生态、手机车联、可穿戴联动、车控体验等。
   - 对新增功能、升级功能、概念展示和量产状态进行区分。

4. 趋势分析节点
   - 基于时间线和品牌维度识别高频方向、差异化能力和潜在产品机会。
   - 输出面向产品团队的观察、启发和待验证问题。

5. 人工复核节点
   - PM 对关键结论、来源可信度和功能归类进行确认。
   - 对不确定信息保留待评估状态，避免把未经验证的内容直接写成产品结论。

6. 简报生成节点
   - 自动生成结构化 HTML 简报。
   - 通过 GitHub Pages 发布为公网访问页面，便于团队快速分享和回看历史版本。

## 展示方式

当前仓库托管的是已生成的静态简报页面。首页 `index.html` 会在 GitHub Pages 上自动列出所有 `fydc-research-*.html` 报告；后续只需新增一期 HTML 报告并提交，目录即可自动更新。
